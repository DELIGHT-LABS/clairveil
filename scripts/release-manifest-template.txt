Notes:
- This is a supplemental selected-file handoff bundle, not a full tracked-source
  archive. Create the latter separately with `git archive` from the same exact
  final commit and record its SHA-256 outside this selected-file bundle.
- For a publishable release, complete and record the required verification on
  the final release commit, create its annotated exact-SemVer tag, create the
  separate full tracked-source archive, then run release-pack and
  release-pack-verify from that tagged commit.
- A snapshot-<full-commit-sha> version is for packaging CI/internal checks and
  must not be published as a release.
- scripts/release-pack-paths.txt selects pack paths and
  scripts/release-pack-required-files.txt defines exact required membership.
- Ignored tmpdocs archives are not release inputs.
- A one-proof 16x32 production-capacity claim additionally requires a tag/commit-bound actual-workload artifact recording proof/sec, tx/sec, item/sec, RSS/CPU, shape distribution, retry/replan/manual-review outcomes, and circuit/artifact/environment identity. Synthetic and legacy results cannot be relabeled as that evidence.
- Downstream production apps must still own EVM/policy/precompile integration,
  audit private key custody, wallet storage encryption, artifact signing, and
  remote prover deployment policy.
